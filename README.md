# Wildan Beckham S - Portfolio

Personal portfolio built with Next.js (static export) for Netlify.

## Stack

- Next.js App Router
- Tailwind CSS v4
- Motion
- Phosphor Icons

## Develop

```bash
npm install
npm run dev
```

## Build (static)

```bash
npm run build
```

Output folder: `out/` (configured in `netlify.toml`).

## Content

Edit static data in `src/data/content.ts`.

Place your CV at `public/cv.pdf` for the download link.
